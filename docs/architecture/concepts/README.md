# Concepts canoniques

Un fichier par concept canonique du projet.

## Convention

- Un fichier `<concept>.md` par concept (kebab-case).
- Définition formelle, contrats, exemples, anti-usages.
- Pointeur vers l'ADR ou les ADRs qui le formalisent.

## Quand créer un fichier ici

Quand un concept apparaît dans ≥ 2 ADRs ou ≥ 2 slices avec une sémantique stable, lui dédier un fichier ici.
