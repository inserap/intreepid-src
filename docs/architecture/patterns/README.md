# Patterns transverses

Cross-cutting patterns utilisés par plusieurs composants du projet.

## Convention

- Un fichier `<pattern-name>.md` par pattern (kebab-case).
- Décrit : quand l'appliquer, comment, alternatives rejetées, exemples.

## Quand créer un fichier ici

Quand un pattern est utilisé dans ≥ 2 composants distincts du projet.
